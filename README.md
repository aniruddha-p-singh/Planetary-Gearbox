# Planetary Gearbox Design

## Overview

This repository showcases the design and development of a 4:1 reduction planetary gearbox created using SolidWorks.

The project was undertaken to strengthen my understanding of gear mechanisms, assembly design, engineering documentation, and mechanical power transmission systems. The final assembly consists of a Sun Gear, Ring Gear, three Planet Gears, Carrier and Shafts.

## Design Specifications

| Parameter              | Value             |
| ---------------------- | ----------------- |
| Gear Type              | Planetary Gearbox |
| Reduction Ratio        | 4:1               |
| Module                 | 1 mm              |
| Pressure Angle         | 20°               |
| Sun Gear               | 12 Teeth          |
| Planet Gear            | 24 Teeth          |
| Ring Gear              | 60 Teeth          |
| Number of Planet Gears | 3                 |

## Key Features

* Complete planetary gear train assembly
* Fixed ring gear configuration
* 4:1 speed reduction mechanism
* Fully constrained SolidWorks assembly
* Exploded assembly visualization
* Engineering drawings and documentation
* Bill of Materials (BOM)

## Components

The gearbox assembly consists of:

* Sun Gear
* Planet Gears (3)
* Ring Gear
* Planet Carrier
* Input Shaft
* Output Shaft

## Motion Study

A motion study was performed to verify the kinematic behavior of the gearbox assembly and ensure proper meshing between the gears.
